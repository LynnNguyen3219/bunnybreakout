# bunny breakout: for jame gam :)
> URL: https://lynnnguyen3219.itch.io/bunny-breakout

bunny breakout is a breakout/brick breaker (obviously) arcade game featuring a little bunny guy who just wants to eat some carrots. maneuver the paddle so that he can eat all of the carrots and clear the level!!!

## features include...
- a working arcade-style breakout game
- crappy pixel art by me (using the official jame gam pallet!!)
- a fully functional start menu
- working audio and sound effects
- particles for extra spice
